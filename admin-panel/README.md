# Admin Panel - Transport Tracking System

React + Vite + TailwindCSS + ShadCN UI admin panel for managing buses, drivers, and viewing real-time tracking.

## Quick Start

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Open http://localhost:3000

4. Login with default credentials:
- Email: `admin@transport.com`
- Password: `admin123`

## Build for Production

```bash
npm run build
```

The built files will be in the `dist/` directory.
